# 验证码弹窗快照

来源页面：`https://nndktr.tnf8enrp.top/pc/#/kb`

- `Captcha.extracted.jsx`：从压缩业务包整理出的验证码交互逻辑。
- `captcha.css`：从 styled-components 模板中还原的验证码区域样式。
- `modal-structure.html`：验证码弹窗的结构快照。
- `captcha-sample.jpg`：页面当次动态加载的 100×45 JPEG 示例；实际运行时应请求 `../vc/qc.php?time=<timestamp>`，不应使用该静态样本进行验证。
- `../assets/svg/close.svg`：弹窗新增的关闭图标。

完整压缩源码仍保存在 `../assets/js/app.bundle.a44facbc.js` 和 `../assets/js/vendors.chunk.124a6ca6.js`。
