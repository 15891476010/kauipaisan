# 快排 SaaS

多租户管理系统、React 用户端、React 代理端、ThinkPHP API、MySQL 数据库迁移与 Redis 会话缓存。

## 目录

- `apps/admin-web`：SaaS 管理端。
- `apps/user-web`：用户端。
- `apps/agent-web`：代理端。
- `server`：ThinkPHP API。
- `online-snapshot`：原线上用户端参考资料。
- `.runtime`：外接盘本地运行时，不提交版本库。

详细实施进度见 `PLAN.md`，AI 开发规则见 `AGENT.md`，历史问题见 `PROBLEM_LOG.md`。
